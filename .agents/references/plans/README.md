# Agent Plans Directory

This directory stores engineering plans, technical proposals, and architectural roadmaps for the development and maintenance of LUG Wine runners.

---

## Active Plans

- [**GLIBC 2.35 Compatibility Plan**](file:///workspaces/lug-wine-experimental/.agents/references/plans/glibc_235_compatibility_plan.md):
  A focused roadmap detailing the skills, MCP servers, and technical phases needed to build and verify a Wine-TKG runner that supports GLIBC 2.35 on the host Ubuntu 22.04 system.

- [**Wine-TKG Skills and MCP Servers Plan**](file:///workspaces/lug-wine-experimental/.agents/references/plans/wine_tkg_skills_and_mcp_plan.md):
  A comprehensive roadmap outlining the required Agent Skills (patch validator, config auditor, binary inspector, prefix verifier) and MCP servers (Clangd, GDB, GitHub, Docker) necessary for general development and quality assurance of custom Wine-TKG runners.
